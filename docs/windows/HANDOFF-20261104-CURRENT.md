- `0029`、`0030` 已归档，不能按补丁目录全量应用；只以 `patches/windows/base.json` 的顺序为准。

- 旧 PID、旧对象地址和旧 UI 指针不可跨进程复用。每次重启都重新扫描实体与 UI。
- `walk_to.py` 的“命中碰撞柱”意味着它会转为 attack/entity goal，不是地面行走；出现 `stopped` 时不能描述为到达。
- 主菜单“继续”会恢复进程内旧会话，不是重新读取磁盘；外部修改存档后必须关闭进程再新启动，否则旧会话的自动存档会覆盖新状态（本轮曾把 920180 覆盖回 930180，已用检查点恢复）。
