# 键盘与鼠标操作说明（Windows KBM 构建）

适用版本：安装版 `F4BF82B64BF2AD1A6B5B7DD0528163820CC3BE0A5979BFFE822C405B23535714`（补丁链至 `0034`）。本文区分“已在当前构建实机验证”与“旧轮次已验证、当前构建沿用源码”的结论。

## 世界与地图

| 操作 | 键/鼠标 | 状态 |
|---|---|---|
| 移动 | `W/A/S/D`，或鼠标左键点地面/可走位置 | 已用于脚本导航；连续精确路径仍需避开碰撞柱 |
| 打开本地大地图 | `Tab` | 当前构建已验证：显示大地图及“新崔斯特姆”区域名 |
| 关闭大地图/取消当前界面 | `Esc` | 当前构建已验证：回到世界与右下角小地图 |
| 打开/关闭背包 | `Enter` 或 `I` | 历史验证；当前构建仍沿用 |
| 打开暂停菜单 | `Backspace` | 当前构建已验证 |
| 关闭暂停菜单 | `Esc` | 当前构建已验证 |

右下角小地图是世界 HUD 的一部分，不能独立关闭；`Tab` 将它扩展为大地图。地图打开时再按 `Tab` 不产生新的输入动作，使用 `Esc` 返回。地图用于查看区域与标记，当前没有把“地图内点击”当成自动寻路接口；移动到目标仍需关闭地图后点击地面或使用已验证的方向导航。

`Tab` 的实现只映射为世界地图动作。菜单已经打开时，运行时不会把 `Tab` 下发成方向键“下”，所以不会误移动菜单焦点；`F2` 运行时菜单也把 `Tab` 视为无操作，方向键才移动焦点。

## 菜单

| 操作 | 键/鼠标 | 状态 |
|---|---|---|
| 上下移动焦点 | `↑` / `↓` | 方向键走原生动作层 |
| 左右切换/调整 | `←` / `→` | 依当前控件而不同 |
| 确认 | `Space` 或 `Enter` | `A` 动作；可被 `keybinds.ini` 的 `a=` 改键 |
| 返回/关闭 | `Z` 或 `Esc` | `B` 动作或全局返回；`Esc` 始终是明确的后退键 |
| 运行时菜单 | `F2` | 打开/关闭；支持方向键、Enter、Space、Esc、鼠标左键与滚轮 |
| 点击菜单行/物品 | 左键 | 已验证：主菜单、暂停菜单行、NPC 对话选项、商人商品行 |
| 全屏 | `F11` 或 `Alt+Enter` | 已实现 |
| 截图（运行时） | `F3` | 已实现 |
| 帮助 | `F1` | 已实现 |

当前 `keybinds.ini` 的六个技能/动作槽位是 `a=Space, b=Z, x=H, y=J, l=K, r=L`。改 `a=` 或 `b=` 后，菜单确认/返回也会跟着改；`Esc` 仍是独立后退键。

## NPC 与铁匠菜单

已验证的通用链路是：鼠标点击 NPC → 游戏自身走近 → 提交 Operate → 对话/菜单打开；打开后点击对话选项或列表行，会走该控件的原生回调。当前构建已重新验证：

- 点击矿工塔苏恩（SNO `178396`）打开商人面板；
- 点击商人商品行命中列表行，日志为
  `native: UI pointer 15 kind 2 control ... row 0 callback 81fb910 -> returned`；
- 莉娅对话的“崔斯特姆 / 圣教军 / 取消”三个选项在 Round 95 已有逐项 UI/回调证据。

需要明确的边界：

- 当前存档只加载了铁匠工作台 `Blacksmith_Crafting_Backbone`（SNO `101123`），没有加载铁匠 NPC（`174023` 或 `204605–204616` 等变体），因此本轮不能声称铁匠 NPC 的铁匠铺菜单已经实机验收。
- 商人/工匠顶部的“购买、出售、修复、回购”页签不是普通列表行。当前通用鼠标路径点击这些页签会记录 `no callback owner`，没有切换页面；这是已知缺口。商品列表行本身可以鼠标选中。
- `0027` 的双按钮确认框回退只覆盖已观察到的固定双按钮形状，尚未完整验证叠加对话框、焦点漂移和其他按钮布局。

后续验收铁匠菜单时应检查：分类页签、配方列表行、可用/不可用配方、固定“制作/升级”按钮，以及材料或物品数量变化。只出现 `operate accepted` 或 UI 高亮不算菜单业务完成。
