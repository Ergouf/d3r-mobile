# 键盘与鼠标操作说明（Windows KBM 构建）

适用版本：当前安装为 `0083`（`DB9BCB81…`，PID `126296`）。在 `0080` 六槽 18 点/左右键 36×16、`0081` 药水 `Q` 标签、`0082` 城镇传送门 picker 基础上，`0083` 修复 mouse UI `focus=UINT64_MAX` 误判；`0083-cold-start.json` 26.299 s 到 world HUD、`success=true`。实机退出确认取消 683→665 且保留暂停、铁匠服务 839→734 世界 HUD，均有 retest。难度弹窗/NPC 对话/叠加提示仍未验；`0082` portal 证据为历史，`0083` 尚未复测。其他冷启动反例保留，不能说启动已整体修复。旧安装版 `0074` 的备份保留，不能称为已通过验收的版本。完整状态见 [交接入口](HANDOFF-20261104-CURRENT.md) 和 [唯一验收清单](KBM-PARITY-20261106.md)。

启动停滞仍在排查：真实问题是自动存档附近的 frame10 Vulkan 提交停滞，此时继续发键无法解除。`0083-cold-start.json` 本次冷启动成功（26.299 s 到 world HUD），但其他冷启动反例仍在，不能据此说启动已修。关闭垂直同步曾成功进入世界，但冷启动仍有反例，不视为可靠修复。标题/开场阶段不是阻塞：启动会自动回播电影，需要间隔约 250 ms 连按两次 `Space`（第一次退出电影，第二次进入主菜单）。

> **输入法提示**：游戏热键必须在英文输入状态使用；中文输入法会截获 `Q` 等按键，导致游戏内动作不触发。2026-11-06 用户在当前安装版上就是在切到英文后确认 `Q` 回血正常。

右下角小地图是世界 HUD 的一部分，不能独立关闭；`Tab` 将它扩展为大地图，再按 `Tab` 关闭。幕内地图节点已用原生鼠标选中并传送，世界页的五幕选择 `0081` 已实机通过。移动到目标需关闭地图后点击地面。

`Tab` 的实现只映射为世界地图动作。菜单已经打开时，运行时不会把 `Tab` 下发成方向键“下”，所以不会误移动菜单焦点；`F2` 运行时菜单也把 `Tab` 视为无操作，方向键才移动焦点。

当前 `keybinds.ini` 的六个技能/动作槽位是 `a=Space, b=Z, x=H, y=J, l=K, r=L`。改 `a=` 或 `b=` 后，菜单确认/返回也会跟着改；`Esc` 仍是独立后退键。

暂停键以世界界面为验收入口。本轮商人面板打开时 `Backspace` 未切到暂停，先按 `Esc` 返回世界，再按 `Backspace` 打开暂停菜单。

背包和技能轮盘现在支持悬停选择：鼠标移入图标即可查看该分类，移出轮盘保持最后选择。选中只切换分类/说明，执行物品或技能操作仍需点击；顶部页签和普通列表也仍需点击。未解锁技能可预览其等级说明，悬停不会绕过解锁条件。秘术师附魔/幻化/染色三页的 14 类装备轮盘也已实测；悬停复用游戏原有图标选中状态及光圈，旧图标取消高亮。铁匠制作的独立武器 13 类、护甲 12 类轮盘已实测。底部“打造/分解/修复/训练”提示左侧区域可点击并走对应原生服务动作；点击右侧其他提示不会误触。
