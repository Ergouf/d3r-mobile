# 键盘与鼠标操作说明（Windows KBM 构建）

适用版本：当前安装为 `0144`（`C83F70E0…`）。键位重绑定位于 F2 → `Keyboard bindings`，当前配置项从 12 项扩展到 22 项：原 12 个战斗/面板动作，加上四向移动、四向菜单导航、确认和取消。Shift 点击可拆分背包中的堆叠物，数量框支持鼠标箭形按钮和接受/取消。

后台启动统一使用 `tools/windows-dev/Launch-Background.ps1`。该脚本只为一个子进程启用 immediate 呈现和同步 GPU 提交，并拒绝同一安装 exe 的第二个实例。`0139` 单实例串行冷启动 4/4 通过；`0140` 当前构建已完成一次启动到世界的冒烟，尚待同样跑满 4 次。普通前台启动继续遵循用户 vsync 设置。

> **输入法提示**：游戏热键必须在英文输入状态使用；中文输入法会截获 `Q` 等按键，导致游戏内动作不触发。2026-11-06 用户在当前安装版上就是在切到英文后确认 `Q` 回血正常。

F2 → `Keyboard bindings` 当前有 22 行：技能 1–4、药水、回城、背包、技能页、任务、巅峰、地图、暂停/返回、移动四向、菜单四向、确认、取消。默认值依次为 `1/2/3/4/Q/T/C/K/J/P/M/Escape/W/A/S/D/Up/Left/Down/Right/Return/Backspace`。`0144` 已完成 F2 全 22 行逐行编辑：`123` 项、`0` 失败；冲突/保留键拒绝、自定义键重启保留、Restore defaults 后重启恢复，以及默认面板/四向移动/菜单/确认取消均已通过。证据 `out/windows/kbm/session/0144-a/`。

`Tab` 的实现只映射为世界地图动作。菜单已经打开时，运行时不会把 `Tab` 下发成方向键“下”，所以不会误移动菜单焦点；`F2` 运行时菜单也把 `Tab` 视为无操作，方向键才移动焦点。

当前 `keybinds.ini` 的六个技能/动作槽位是 `a=Space, b=Z, x=H, y=J, l=K, r=L`。改 `a=` 或 `b=` 后，菜单确认/返回也会跟着改；`Esc` 仍是独立后退键。

暂停键以世界界面为验收入口。历史验收中，商人面板打开时 `Backspace` 未切到暂停；先按 `Esc` 返回世界，再按 `Backspace` 才能打开暂停菜单。

背包和技能轮盘现在支持悬停选择：鼠标移入图标即可查看该分类，移出轮盘保持最后选择。选中只切换分类/说明，执行物品或技能操作仍需点击；顶部页签和普通列表也仍需点击。未解锁技能可预览其等级说明，悬停不会绕过解锁条件。秘术师附魔/幻化/染色三页的 14 类装备轮盘也已实测；悬停复用游戏原有图标选中状态及光圈，旧图标取消高亮。铁匠制作的独立武器 13 类、护甲 12 类轮盘已实测。底部“打造/分解/修复/训练”提示左侧区域可点击并走对应原生服务动作；点击右侧其他提示不会误触。
