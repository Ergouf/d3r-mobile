## 口径

- “已完成”必须有当前构建的实机可观察结果：`place`、HP、物品位置/数量、UI 选中页或可见文本。
- “部分”表示有实现或旧构建证据，但当前构建缺少完整验收，或只覆盖部分路径。
- “未完成”表示用户实测失败或只有桩测试，不能作为交付。
- “离线不适用”是纯离线单人环境没有对端的 PC 功能，不纳入交付。
